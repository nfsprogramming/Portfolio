# 3D Animated Portfolio — Implementation Plan

## Overview
Build a futuristic, immersive 3D portfolio inspired by alche.studio: dark cosmic aesthetic, scroll-driven animations, a floating 3D object in the hero, smooth section transitions, and a polished works gallery. Stack: **Vite + React + React Three Fiber (Three.js) + Framer Motion + GSAP**.

## Tech Stack & Dependencies
- **Build**: Vite (React + TypeScript)
- **3D**: three, @react-three/fiber, @react-three/drei, postprocessing (bloom)
- **Animations**: framer-motion, gsap, lenis (smooth scroll)
- **Styling**: Plain CSS modules / a single global stylesheet (no Tailwind to keep it lean and bespoke)
- **Icons**: lucide-react

## Key Features (mirroring alche.studio)
1. **Hero 3D scene**: a floating distorted metallic object (procedural geometry + custom vertex/fresnel shader) that rotates with mouse and reacts to scroll; bloom postprocessing for the glow. *No external GLTF required* — driver-shaped knot/torus knot geometry w/ iridescent shader gives the "floating 3D object" look. The component is structured so a real `.glb` can be swapped in via drei's `useGLTF` later.
2. **Background particle starfield**: 2000+ instanced points drifting with subtle parallax tied to scroll.
3. **Smooth scroll**: Lenis synced with GSAP ScrollTrigger for momentum + section pinning.
4. **Section reveals**: Framer Motion `whileInView` stagger for headings/text/lines.
5. **Works grid**: 6 projects with 3D tilt-on-hover cards, image overlays, tags, and a "View work →" magnetic link.
6. **Horizontal-scroll Process timeline**: pinned, translated horizontally as user scrolls.
7. **Custom magnetic cursor**: grows and labels on interactive elements.
8. **Preloader overlay**: animated counter 0→100% then curtain reveal.
9. **Glass navbar + smooth-scroll anchors; "Contact"/"Resume" CTA**.
10. **Responsive** + reduced-motion fallback (disable Lenis/particles for `prefers-reduced-motion`).

## Dev & Run Steps
1. `npm create vite@latest . -- --template react-ts` (scaffold into current dir)
2. Install deps: three @react-three/fiber @react-three/drei postprocessing framer-motion gsap lenis lucide-react
3. Wire `vite.config.ts`, `tsconfig` (add GLSL/`*.glsl.json` if needed — but we'll inline shaders as template strings to avoid extra loaders).
4. Build files per structure above.
5. `npm run dev` → verify on http://localhost:5173; `npm run build` → verify it compiles.
6. Write `README.md` with run/deploy notes.

## Deliverable
A running dev server + a production build that compiles cleanly, deployable to Vercel/Netlify/any static host as-is. Swap-in points for real content documented in README.

## Out of Scope (kept simple on purpose)

- Per-project detail pages (each work card links out / shows modal) — single-page site.
